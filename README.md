# David Weng Portfolio

Portfolio site of David, focused on visual storytelling, design, content operations, and AI-integrated creative workflows.

## Stack

- Next.js 16
- React 19
- TypeScript
- Vitest + Testing Library

## Local Development

```bash
pnpm install
pnpm dev
```

## Verification

```bash
pnpm test
pnpm lint
pnpm build
```
